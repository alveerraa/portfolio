# 🌐 Alveera Ahmad — Portfolio

A dark editorial-themed personal portfolio showcasing my work in **Cloud Computing, DevOps, and Full Stack Development**. Built with vanilla web technologies and deployed via GitHub Pages — originally prototyped on AWS S3.

## ✨ Live Demo

👉 **[alveerraa.github.io/portfolio](https://alveerraa.github.io/portfolio/)**

---

## 🎨 Design

- **Editorial dark theme** — deep black background with warm cream typography
- **Custom typography pairing** — Fraunces (display), Instrument Serif (italic accents), JetBrains Mono (labels)
- **Signature accent color** — burnt orange (`#ff4d29`)
- Subtle film-grain texture and ambient color glows
- Designed to feel like a magazine, not a template

---

## 🛠️ Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, grid, advanced animations
- **Vanilla JavaScript** — no frameworks, no dependencies
- **ScrollReveal.js** — scroll-triggered reveal animations
- **Boxicons + Font Awesome** — iconography
- **GitHub Pages** — deployment & hosting
- **AWS S3** — initial prototype hosting

---

## 💡 Features

- 🖱️ **Custom cursor** with trailing ring and hover states
- ⏳ **Animated page loader** on first visit
- ✨ **Cascading hero text reveal** with hand-drawn underline
- 🌀 **Infinite scrolling marquee** between sections
- 📊 **Editorial-style skills list** with hover-activated progress bars
- 🖼️ **Floating image preview** that follows your cursor on project cards
- 💬 **Philosophy section** with gradient quote typography
- 📝 **Validated contact form** with mailto integration
- 📱 **Fully responsive** with custom mobile nav
- 🎯 **Active section highlighting** in nav as you scroll
- 🌑 **Dark theme by default** with cohesive accent palette

## ☁️ Deployment History

Originally deployed to **AWS S3** as a static website hosting experiment to learn cloud deployment workflows. Later migrated to **GitHub Pages** for easier continuous deployment from the `main` branch.

### AWS S3 Setup (for reference)
1. Created an S3 bucket with static website hosting enabled
2. Uploaded all files with public read permissions
3. Set `index.html` as the index document
4. Tested access via the public S3 URL
5. *(Hosting was disabled post-testing to avoid charges)*
